# pkg

Application resources for the console.

- `icon0.png`: icon of the websrv tile (512x512), copied to `Pelagia/sce_sys/icon0.png` by the PS5
  build. Generated by `tools/make_icon.py` (Noto Sans Bold, `assets/fonts`).
- `pelagia.conf.example`: example of a pre-configuration file (`server=` only), see `README.md`.

A future version will add the resources of a home-screen title (param, background, title, ID).
